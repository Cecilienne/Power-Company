# 游戏内界面 · 风格与排版

> 与 `docs/ui_start_screen.md` 同一套色板。启动页与游戏页不再各穿一件衣服：
> 黑底 + 白字 + 蓝/红/黄三个色块，绿色只表示"正常"。

## 1. 色板（`pwer/constants.py`）

| 常量 | 值 | 用在哪 |
|---|---|---|
| `UI_BG` | `#0B0B0C` | 画布底、左轨底、顶栏底 |
| `UI_PANEL` | `#14151A` | 抽屉、面板 |
| `UI_PANEL2` | `#1A1C22` | 面板内的二级块（抽屉标题条、列表底、普通按钮） |
| `UI_HOVER` | `#24262E` | 悬停底、滑块槽 |
| `UI_RULE` | `#26262B` | 1px 分隔线 |
| `UI_TEXT` / `UI_DIM` / `UI_DIM2` | `#F4F2EC` / `#A6A6AC` / `#55555C` | 主文 / 次文 / 注释 |
| `UI_BLUE` | `#21449C` | 时间块（回合 / 年季 / 结束回合） |
| `UI_RED` | `#E1251B` | 主行动（结束回合、运营页签、退出） |
| `UI_YELLOW` | `#F2E600` | 强调数字（股价、电价、KPI）与章节标题 |
| `UI_GOOD` / `UI_BAD` | `#35C15A` / `#E1251B` | 盈亏、涨跌 |

规则：

* **线只有 1px**。启动页的页脚线、顶栏的数据条底线、面板分隔线统一 1px `UI_RULE`，
  不再出现 3px 粗边。
* **红色只给"按了就发生大事"的按钮**：结束回合、退出、运营页签选中态。
* **黄色只给"要看的数字"**：股价、电价、分红、信誉；不用来装饰边框。
* **绿色只表示状态正常**（校验通过、盈亏为正、单机模式灯）。

## 2. 顶栏

```
现金   负债   股价   市值   市占   监管阶段        ┌──────────────────────────┐
8.00亿 2.00亿 12.00  16.85亿 0.0%  扩张期          │ 第 1 回合 · 2025年春季    │
                                                    │ 扩张期 · 需求 1,980MW  ▶结束回合 │
                                                    └──────────────────────────┘
```

* 左：6 个数据格，标签 8pt 灰、数值 11pt 粗体（股价用 `K_UP`/`K_DOWN`，市值绿、市占黄）。
* 右：`UI_BLUE` 色块，回合 12pt 粗体、年季 8pt 灰、`结束回合 ▶` 用 `Accent.TButton`（红底）。
* 底边 1px `UI_RULE`。

## 3. 左轨

* 宽 116（逻辑像素），左缘 3px `UI_YELLOW` 竖条贯穿到底。
* 三个页签：政策 / 股市 / 公司，中文 11pt 粗 + 英文 7pt。
* 选中项：整块 `UI_RED` 底、白字、左缘黄条；未选中 `UI_PANEL2` 底、灰字。
* 分隔线以下「其它 / MORE」：`菜单 / 存档 / 读档 / 规则` 四个中性按钮，最后单列一枚红底「退出」。
* 所有按钮 `cursor="hand2"`，悬停底 `UI_HOVER`。

## 4. 抽屉（右侧覆盖层）

* 宽 `min(500, max(360, 0.44 × 舞台宽))`，底色 `UI_PANEL`、1px `UI_RULE` 边框。
* 标题条 `UI_PANEL2`，标题 10pt 粗体，右侧 `✕` 关闭。
* **内容可滚动**：Canvas + `ttk.Scrollbar`（样式 `Dark.Vertical.TScrollbar`），
  鼠标滚轮在抽屉内生效，离开就解绑——1240×736 下运营页装得下全部内容。
* 三个页签：政策·日志 / 股市·行情 / 公司·经营财报；公司页内再分「运营 / 财报」。

## 5. 排版规矩

* 左右内边距 8（`scale.px(8)`），区块之间 3–6。
* 章节标题 10pt 粗体 `UI_YELLOW`；表头 9pt 粗体 `UI_DIM`；正文 9pt。
* 长文本自己断成两行（资金/债务、班组/声望），不塞进一行后横向截断。
* 数字右对齐、单位跟在同一行，避免"8.00 亿"被拆开。
* 表格（`ttk.Treeview`）行高 20、无边框、选中行 `UI_SEL`（蓝）白字。

## 6. 返回主菜单

* 入口：左轨「菜单」，或启动页/游戏页的 `Esc`（游戏内 `Esc` 先退建造模式、再关抽屉）。
* 行为：确认框「返回主菜单？当前进度会写入自动存档。」→ `save_game(silent=True)`
  写 `autosave.pkl` → 清掉建造模式/选中地块 → 关抽屉 → 解绑游戏内快捷键 → 铺回启动页。
* 窗口不重建：启动页是盖在同一个 `App` 上的覆盖层，音乐与窗口状态都不断。

## 7. 背景音乐

* 开关在启动页「设置 → 03 音频」，取值 `关` / `开 · BGM 01`；关闭时显示 `不可用`。
* 文件：`assets/bgm/bgm_01.mp4`（`--add-data "assets;assets"` 打进发行包）。
* 后端：`mfplay.dll`（Media Foundation）经 ctypes 调用，画面渲染进 1×1 隐藏窗口，
  只出声不出画；播完由 1.5s 定时器 `poll()` 归零重播。
* 打不开就退回「关」并弹一次原因说明——**不做点了没声音的假开关**。
