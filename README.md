# 电力公司 · Power Company

2D 回合制「电力经营 + 证券并购博弈」模拟游戏：经营电网决定财报，财报决定股价；用电价战术打压对手，在股市收购对手，同时提防 AI 吞并你。

本仓库只保留游戏运行代码。运行不需要安装第三方包，Python 3.10+（带 tkinter）即可。

## 运行

```bash
python main.py                 # 启动：先进启动页，点【开始】进游戏
python main.py --seed 2026     # 指定地图/随机种子
python main.py --selftest      # 无窗口自检（引擎 + tkinter）
python main.py --audio-test    # 只验背景音乐，响 3 秒
```

启动页：`↑↓` 选菜单、`Enter` 确认；选到【设置】时 `←→` 改值，`Esc` 退出。设置第 5 行显示当前主题「深蓝 · 黑」。

## 操作

- 顶部数据条：现金 / 负债 / 股价 / 市值 / 市占 / 监管阶段；右上角结束回合。
- 左侧页签：政策 / 股市 / 公司；其它：菜单 / 存档 / 读档 / 规则 / 音乐。
- 底部建造条：选建筑 → 地图高亮可建地块 → 点击确认；再点【取消】退出。
- 鼠标悬停地块看造价与不可建原因；点击城市看各公司份额。
- 快捷键：`Ctrl+Enter` 结束回合，`Esc` 退出建造/收起抽屉，`Ctrl+1~3` 开政策/股市/公司，`F11` 全屏切换。

## 玩法要点

1. 每座电厂每季度都扣折旧与运维，产能过剩会直接吞掉利润。
2. 电厂要和「城市 2 格内的变电站」通过相邻线路连成一片；城市接口容量有限，线损随距离上升。
3. 份额由电价、可靠性和口碑决定；只降价不建产能没有意义。
4. 财报决定股价：5% 举牌 / 20% 董事席位 / 51% 控股 / 75% 吸收合并；负债过高、连续亏损时，AI 也会收购你。

## 目录

```
main.py                  启动入口与自检
pwer/
  constants.py           全部可调数值
  terrain.py             地形生成
  world.py               地块、资源、建造权限
  company.py             公司、电厂、矿、利润表
  grid.py                电网连通、可交付容量、线损
  dispatch.py            需求分流、机组调度
  valuation.py           股价模型
  ma.py                  股权、回购、增发、控股、合并
  policy.py              碳税、配额、电价上限、反垄断
  events.py              随机事件
  ai.py                  对手 AI
  engine.py              回合编排与结算
  ui/                    启动页、主窗口、地图、设置
config/
  terrain_config.json    地形生成参数（可选；缺省用代码内默认值）
```

## 存档

优先写入 `%APPDATA%\PowerCompany\`，不可写时回落到游戏目录下的 `saves\`。
手动存档为 `saves/slot1.pkl`；开启自动存档后每回合写 `saves/autosave.pkl`。

背景音乐可选：把 `mp3 / m4a / aac / mp4 / wav / wma` 放进存档目录下的 `bgm\`，游戏内左轨【音乐】选择曲目。
